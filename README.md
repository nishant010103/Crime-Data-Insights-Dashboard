# 🚔 Crime Data Analysis Dashboard

An interactive Power BI dashboard designed to analyze crime trends, crime categories, regional patterns, and yearly crime statistics using data visualization techniques.

---

## 📌 Project Overview

This dashboard helps in understanding:

- Crime trends over time
- State-wise crime distribution
- Most affected regions
- Crime category comparison
- KPI analysis for total crimes
- Data-driven insights for better decision making

---

## 🛠️ Tools & Technologies Used

- Power BI
- Excel
- Data Visualization
- Data Cleaning
- DAX (Basic Measures)

---

## 📊 Dashboard Features

✅ Interactive Filters & Slicers  
✅ KPI Cards  
✅ Clustered Bar Charts  
✅ Line Charts for Trend Analysis  
✅ State-wise Crime Comparison  
✅ Dynamic Visual Insights  
✅ Professional Dark Theme Design

- Analyzed category-wise crime distribution
